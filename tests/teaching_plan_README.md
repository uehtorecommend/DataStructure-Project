# 实验2排课回归

运行 `python3 tests/test_teaching_plan.py -v`，或加 `--sanitize` 启用 ASan/UBSan。
完整菜单程序和 include 原源码的测试驱动均以 C++11、严格警告编译。

最短时间策略现在按递增期限搜索，按后续关键路径长度选择拓扑序，枚举每门课的所有合法学期，利用先修关系、最晚学期、课程/学分容量及未来可放位置剪枝。每个期限最多展开200000个结点，递归深度最多100，避免无限回溯；预算耗尽返回 unknown，不宣称无解。如果较小期限搜索耗尽预算，随后找到方案则明确标为可行但未证明最短。无解只来自必要约束或完整搜索。算法最坏情况指数复杂度，不保证所有规模都能在预算内求解。当前交互参数最多8学期、每期5门，因此100门输入会直接通过课程容量约束判定不可行；40门独立课程可快速完成。

覆盖原4门反例、独立课程装箱反例、先修链、课程/学分限制、小数学分、循环依赖、单课超限、40/100门输入，以及强制零预算的 unknown 状态。180个固定种子随机实例由独立的逐学期子集穷举器验证可行性与最少学期数。检查每份成功计划的课程唯一性、先修严格跨学期与两种容量约束。

完整菜单交互测试复现用户流程；均匀分布策略的导出文本与修改前完整程序生成的 `fixtures/teaching_even.txt` 逐字节比较，另测最短计划导出。均匀分布策略本身保持不变；不对其启发式完整性作额外保证。仅修改 `DataStructure-Project/` 内的维护版本，根目录历史版本未变。

原维护源码使用GB18030，本次转为UTF-8，使测试与常规Linux C++编译直接可用。可用UTF-8打开文件并编译。容器限制导致本地LeakSanitizer不能访问进程信息，本地ASan/UBSan运行使用 `ASAN_OPTIONS=detect_leaks=0:halt_on_error=1`；GitHub Actions正常启用泄漏检测。
